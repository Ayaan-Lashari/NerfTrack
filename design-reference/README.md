# Nerfify design reference

These images are visual references for the first implementation pass:

- `dashboard-reference.png` is the supplied dashboard concept and is the locked visual reference for the home surface.
- `setup-reference.png` is the supplied first-run direction. It is not treated as an approval artifact.
- `first-run-concept.png` is a derived implementation concept generated from the supplied references to resolve setup layout, copy, and panel hierarchy.

The implementation keeps UI text and controls code-native. The images are never used as rendered application UI.
